How to Report a Potential Vulnerability?
========================================

If you would like to report a public issue (for example, one with a released
CVE number), please report it as a
[GitHub issue](https://github.com/arduino/meta-arduino/issues/new).
If you have a patch ready, submit it as a pull request following the usual
contribution workflow.

If you are dealing with a not-yet released or urgent issue, please contact us
via Qualcomm's [Product Security team](mailto:product-security@qualcomm.com) or
see their
[Report a Bug](https://www.qualcomm.com/company/product-security/report-a-bug)
page, including as many details as possible: the layer or recipe affected, its
version, and any example code, if available.

Branches maintained with security fixes
----------------------------------------

We only accept patches for the `master` branch and any other actively
maintained release branch.
